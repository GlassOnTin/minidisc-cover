Foldable case inserts at true size, printed from the browser. Nothing is uploaded anywhere — the image never leaves this page.

Artwork

Square artwork works best. Anything else is centre-cropped to the front face, never squashed.

Corner

The ruler is the only way to catch the print dialogue silently rescaling. Leave it on for a first print, off once you trust the setup.

Case geometry

Set the print dialogue to 100% scale, not “fit to page”, and A4 paper. Then measure the ruler before cutting.

Preview

Front face is 68 mm because that is the disc cartridge's own height (72 × 68 × 5 mm). The spine band is the case thickness. Measure yours — published figures for the rest disagree with each other.
